# Demo 演练手册（3 分钟）

本手册用于 iCAN 现场演示的彩排与正式演示，目标是在 **3 分钟内完整、稳定**地展示
「组卷 → 答题卡 → 学情报告」一条龙教学闭环（代号 **W0**），并留出「AI 教案」作为备用彩蛋。

> ⚠️ 安全提醒：全程**不要展示 API Key**，不要打开 `.env` 文件，不要在终端输入含密钥的内容。
> 日志只记录 prompt 摘要 / 耗时 / token，不含密钥（D5 已保证）。

---

## 0. 一句话定位（开场话术）

> 「智教助手 EduMate 是一个面向教师的智能教学助手：老师只需要说一句自然语言，
> 它就能自动完成从出卷、排版试卷、制作答题卡，到批改统计、生成学情报告的全流程，
> 把老师从重复性事务中解放出来。」

- [ ] 种子数据完整（启动日志出现 `种子数据校验通过：7 个知识点 / 10 道题 / 20 名学生`）

- [ ] 浏览器打开 http://127.0.0.1:8000 前端页面正常
- [ ] 网络稳定、无 VPN/代理干扰（DeepSeek 需可达）

| 时间 | 环节 | 操作 | 观察点 / 话术要点 |
|---|---|---|---|

## 3. W0 完整演示流程（逐步操作）

### 步骤 1：启动后端

```bash
.venv\Scripts\python.exe -m uvicorn main:app --app-dir backend --host 127.0.0.1 --port 8000
```

看到 `种子数据校验通过` 与 `EduAgent 启动完成` 即就绪。

### 步骤 2：打开前端

浏览器访问 http://127.0.0.1:8000 ，确认对话 / 任务输入区与产物区显示正常。

### 步骤 3：提交 W0 任务

在任务输入框输入（建议提前复制，避免现场手打错字）：

```text
请对《一元二次方程》做章节小测并生成学情报告
```

### 步骤 4：观察步骤时间线

引导评委关注时间线上依次出现的节点（约 8 步）：

1. `understand_task` — 识别意图为「章节小测一条龙」
2. `fetch_knowledge` — 检索到 7 个知识点
3. `generate_exam` — 加载题库 10 道题
4. `build_exam_docx` — 生成试卷 docx
5. `build_answer_sheet` — 生成答题卡 xlsx
6. `load_student_answers` — 加载 20 名预置答题
7. `analyze_scores` — 成绩统计（平均分 / 及格率）
8. `diagnose` → `build_report_pdf` — 生成学情报告 pdf

> 讲解话术：「注意看，它不是一键出卷，而是像一位老师一样，一步步思考、调用工具、产出文档。」

### 步骤 5：预览与下载产物

- 点击「试卷」预览 → 展示排版规范的 Word 试卷
- 点击「答题卡」预览 → 展示可直接打印的答题卡
- 点击「学情报告」预览 → 展示含平均分、及格率、薄弱知识点的 PDF 报告
- 分别点击「下载」，强调产物是「可直接使用」的 docx / xlsx / pdf

### 步骤 6（备用彩蛋）：AI 教案

```text
帮我写一份《一元二次方程》的教案
```

展示结构化教案：教学目标、重点、难点、教学过程、课后作业。

**稳定性验收**
- [ ] 连续 3 次运行 W0 均成功（现场不翻车）
- [ ] 断网 / 超时场景下能给出友好错误提示，不出现未捕获崩溃
- [ ] 启动时种子数据校验通过；人为删除任一 seed 文件后启动失败并给出明确文件名

**安全验收**
- [ ] 全程未出现 API Key（界面 / 终端 / 日志 / 录屏）
- [ ] `.env` 未被提交进 Git

## 6. 录屏注意事项

- **分辨率**：建议 1920×1080，统一浏览器与终端缩放，保证文字清晰可读。
- **时长**：严格控制在 3 分钟内；若时间紧张，只保留 W0 主流程，教案作为彩蛋剪掉即可。
- **音画**：建议配合口播；若静默录制，需叠加字幕或文字说明，否则关键步骤不易被理解。
- **隐私**：录屏前关闭无关通知、清理桌面；**不展示 `.env` / 密钥**；如需演示配置，只谈「从环境变量读取」。
- **画面焦点**：提前规划镜头焦点切换 —— 输入框 → 步骤时间线 → 产物预览 → 下载文件；避免长时间停留在空白区域。
- **存档**：录屏导出为 mp4，命名含日期与版本（如 `EduMate_Demo_2026-08-27.mp4`），连同产物截图一起归档到统一目录。
