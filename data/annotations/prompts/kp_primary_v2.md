## 主知识点消歧规则（v2 新增，必须遵守）

1. **应用题**：primary 取最具体的教学考点（如"工程合做"取工程问题，而非"四则混合运算"）；
   **纯计算题**（题面即为算式求值）：primary 取对应运算类 KP。
2. **表层关键词不决定 primary**：某关键词出现（如"速度""每小时行 X 千米"）不代表题目考查对应
   知识点——必须看设问本质。反例：路程固定、速度变快求时间，本质是归总+反比例，不是行程问题。
3. **相邻知识点边界**（用清单内定义判断）：
   - 量率对应（求一个数的几分之几/倍数互化）vs 比与按比例分配（按比例分、化简比）：倍数↔分数互化
     归量率对应，按比例分配归比；
   - 整除特征（整除性与倍数链判断）vs 因数与倍数（概念与求解）：判断"能不能被整除/是不是倍数链"
     归整除特征；
   - 率类问题（发芽率/出勤率/含盐率等百分率）vs 浓度问题（溶质溶液比例变化过程）：求一个百分率数值
     归率类，蒸发/稀释等变化过程归浓度；
   - 找规律（数列与图形规律）vs 简便计算（运算律与凑整技巧）：裂项相消等凑整归简便计算；
   - **加减运算（整数加减·一步）vs 四则混合运算**：一步整数加减归加减运算；**两步及以上（含纯加减
     两步）归四则混合运算**。
4. **应用题不给通用运算类辅助**，除非该运算本身就是题目明确考查的对象；**关键词出现 ≠ 考查依据**；
   **不为提高覆盖率而扩大标签数量**。

## 输出 JSON 格式（严格遵循，不要输出 JSON 以外的任何内容）

```json
{"primary": "kp_p_xxx", "kp_ids": ["kp_p_xxx"], "difficulty": 3,
 "confidence": {"kp": 0.9, "difficulty": 0.8}, "reason": "主考点≤15字；辅助依据≤15字"}
```

字段要求：
- `kp_ids`：1–3 个字符串数组，第一个视为 primary 的同位元素；**辅助允许为空**
  （即 `kp_ids` 可仅含 primary 一个）——每个辅助都必须有**明确题目依据**，宁缺勿滥
- `primary`：最主要知识点，必须包含在 `kp_ids` 中
- `difficulty`：1–5 的整数
- `confidence`：`kp` 与 `difficulty` 各为 0–1 数值
- `reason`：不超过 30 字——先写主考点判断依据；若有辅助，再写每个辅助的题目依据
- **若题目不属于清单中任何知识点**：`kp_ids` 用 `[]`、`primary` 用空字符串 `""`，
  并在 `reason` 中说明原因——这是有效结果，不要勉强硬挂

## 难度锚点

- 1 = 一步运算或直接作答
- 2 = 两步内常规应用题
- 3 = 两至三步，含简单组合或单位换算
- 4 = 多步复合、隐含条件或多知识点组合
- 5 = 需要巧妙构造或竞赛级多重嵌套

## 题干记法说明（以下均为合法题目结构，不是数据损坏，不要因此拒判或降低置信度）

- `((())/(()))`、`()` 等空括号串：填空题的待填空位
- `*`：乘号；`**`：指数（如 `cm**3` 即立方厘米）——python 记法，不是 Markdown
- `(3/4)`：分数四分之三
- `n(a/b)`：带分数（如 `2(1/3)` 即二又三分之一）
- `%`：百分数
- `{_{..}}`：循环小数记法
